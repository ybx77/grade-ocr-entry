# 成绩录入 · Grade OCR Entry

给老师用的小工具：手机对着实验报告拍一张照，OCR 自动认出**姓名**和**成绩**，核对后一键入库，最后导成 CSV/Excel。

🔗 在线使用：<https://chengji-peach.vercel.app>

纯前端实现，照片和成绩都留在本机浏览器里，不上传任何服务器。

## 为什么用它

手工把纸质实验报告的分数一个个敲进表格，一个班就要半小时。这个页面把流程压成三步：拍照 → 确认 → 导出。

## 功能

- **拍照 OCR**：手机或电脑摄像头拍报告，Tesseract.js 在本地识别中文 + 英文
- **姓名交叉校验**：导入班级名单（Excel），识别出的姓名会和名单比对，防止认错人
- **确认后录入**：OCR 结果先展示出来，人工改完再入库，不会直接写脏数据
- **本地存储**：录入记录存在浏览器里，刷新不丢
- **一键导出**：导出为 CSV，Excel / WPS 直接打开

## 使用步骤

1. 打开页面（推荐手机，拍照方便）
2. 首次使用先导入学生名单，格式见下方说明
3. 点拍照，对准报告的姓名和分数区域
4. 检查识别结果，不对就手改
5. 确认录入，全部录完点导出

## 手机怎么用

最省事的办法是部署到 Vercel（本仓库已部署），手机直接开网址。

想在本机跑、手机同局域网访问：

```bash
python3 -m http.server 8080
# 电脑上查 IP，例如 192.168.1.100
# 手机浏览器打开 http://192.168.1.100:8080/index.html
```

> 浏览器只在 HTTPS 或 localhost 下允许调用摄像头。用 `http://` + 局域网 IP 时，部分浏览器会拒绝开摄像头，这种情况挂到 HTTPS 上更稳。

## 名单格式

Excel 第一列放学生姓名即可，表头随意，导入时程序会自动跳过表头行。

## 目录结构

| 文件 | 说明 |

## 隐私

OCR 和数据处理都在浏览器内完成，图片不外传、成绩不上传。清理浏览器数据会一并清掉已录入的记录，记得先导出。
